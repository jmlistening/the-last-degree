# 视觉审查

基线取自原版 Edge 游戏截图。新手小镇中，住宅、医院和商业楼大多沿用同一方盒轮廓和窗格，材质共享单一粗糙度。暖灰地面和均匀暖光削弱了材质层次。河道只有静态短线，路面缺乏高差和城市服务设施，底座边缘缺少细节。冷却塔粒子聚集在塔顶，地图上很难读出冷却覆盖及重点建筑温度的变化。镜头拖动已经带阻尼，旋转按钮仍会瞬间跳转。桌面底部的建造面板和右侧竖排控件分散了操作，手机上可用场景面积更小。

验收先以新手小镇为基准，检查建筑剪影、普通视图里的冷热区分、预览是否与合法地块一致，以及真实浏览器里的部署、通关和手机离线流程。

## 渲染与交互

建筑由程序化几何生成，按几何和表面材质批处理。窗灯、标识与河岸灯走独立亮色批次，路灯用局部加色辉光。场景使用冷色环境光、边缘补光、阴影和深度雾。高温波纹采用局部透明着色器，画面清晰度优先于全屏后处理。

冷却圈使用设施半径和风向显示覆盖。地块根据实际模拟温度渐变，重点建筑显示实时读数。高画质场景只在设备状态变化和建造动画期间刷新阴影图。移动端默认使用轻量画质，直接点地图时先预览，再点同一格确认部署。网格面板仍可一键精确建造。

## 验证

- 正式构建与 TypeScript 检查通过。Vitest 15 项、pytest 4 项、Playwright 3 项通过。
- 新手小镇浏览器用例包含部署、温度标记变为达标、速度切换、暂停、通关、失败和存档恢复。其他七关检查实际渲染；终局额外触发降雨。手机视口验证断网重载、网格部署和地图两次轻触确认。
- 性能抽样使用本机 Edge、ANGLE SwiftShader 软件渲染、1360 × 840 视口，新手小镇部署两座冷却塔后各采样约 2.5 秒。自适应后画布为 1156 × 615。高画质记录 53 个帧间隔，p95 为 66.6 ms；轻量画质记录 120 个帧间隔，p95 为 30.3 ms。这里记录的是浏览器动画帧间隔。未测量真实手机、Safari 或硬件 GPU 表现。
